# Security and Confidentiality Notice

This repository is a **sanitized portfolio case study**.

It intentionally excludes confidential or proprietary employer information.

## Do not commit

- database passwords;
- connection strings;
- production server names or IP addresses;
- VPN or network details;
- customer data;
- employee data;
- material/product master data;
- production logs;
- proprietary SQL schema/table names;
- screenshots containing confidential company information;
- complete employer-owned source code unless written authorization exists.

## Configuration

Use placeholder configuration only, for example:

```json
{
  "ConnectionStrings": {
    "SourceDatabase": "REDACTED",
    "TargetDatabase": "REDACTED"
  }
}
```

## Public Portfolio Purpose

The purpose of this repository is to demonstrate:

- architecture;
- system-integration design;
- reliability thinking;
- duplicate prevention;
- operational monitoring;
- enterprise software engineering.

It is not intended to reproduce or distribute an employer's production system.
